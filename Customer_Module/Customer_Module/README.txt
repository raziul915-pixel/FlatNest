FLATFINDER - CUSTOMER MODULE (HANDOFF PACKAGE)

This folder is the complete Customer (Buyer) frontend module.
It includes all HTML pages, CSS styling, and JavaScript functionality in one folder.

PAGES INCLUDED
- index.html: Customer home page
- register.html: Customer registration
- login.html: Customer login
- reset-password.html: Demo password reset
- dashboard.html: Personalized customer dashboard
- search-flats.html: Search and filter flats by project, location, size, bedrooms, floor, and price range
- flat-details.html: Flat details, photo gallery, floor plan, price, and availability label
- wishlist.html: Saved/shortlisted flats
- inquiries.html: Send inquiry and view inquiry history/reply field
- profile.html: View/edit profile, upload profile picture, change password, delete account

RUN
1. Extract the ZIP.
2. Open Customer_Module/index.html in a browser, or open Customer_Module in VS Code and run with Live Server.
3. Register a customer account, then log in.

GROUP HANDOFF
The student responsible for the Customer module can hand this entire Customer_Module folder to the group member managing the main repository. Keep the folder structure unchanged when copying it into the group project. The group member can then connect the module's inquiry and flat data to the shared project backend if the project uses one.

TECHNICAL NOTE
This is a pure HTML, CSS, and JavaScript frontend demo. It uses browser localStorage and sample flat records. Login/password handling is for demonstration only, not secure production authentication. Availability labels are sample data, not live server updates. Customer inquiries and reply fields are stored locally; actual replies from the Sales Agent module require a shared backend/database/API. The floor plan is illustrative and should be replaced with the actual project plan if supplied.
